# GitHub Dark — Theme for Omarchy

A GitHub Dark theme for [Omarchy](https://omarchy.org/), bringing the familiar
colors of GitHub's dark mode to your desktop environment.

## Installation

```bash
omarchy-theme-install https://github.com/lone/omarchy-github-dark
```

## Color Palette

| Color   | Hex       | Usage              |
| ------- | --------- | ------------------ |
| `#0d1117` | Background  | Base background    |
| `#161b22` | Surface     | Elevated surfaces  |
| `#21262d` | Border      | Borders, overlays  |
| `#e6edf3` | Foreground  | Primary text       |
| `#58a6ff` | Blue        | Accent, links      |
| `#3fb950` | Green       | Success            |
| `#d29922` | Yellow      | Warning            |
| `#ff7b72` | Red         | Errors, failures   |
| `#bc8cff` | Purple      | Extras             |
| `#39c5cf` | Cyan        | Info               |
